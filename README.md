# rhino-privacy-policy
Rhino Bot, Discord sunucularında moderasyon ve destek süreçlerini kolaylaştırır. Bot; yöneticilerin timeout ve ban işlemlerini yönetmesine, ticket sistemi üzerinden kullanıcı destek taleplerini düzenli şekilde takip etmesine yardımcı olur. Sunucu yapılandırmaları ve gerekli kanal bilgileri botun çalışması için saklanır.
